# 💰 Student Expense Tracker

A simple and user-friendly desktop application designed to help students manage and monitor their daily expenses.

## 📌 About the Project

The Student Expense Tracker is developed using Python and Tkinter. It allows users to record expenses, organize them into categories, search transactions, delete expenses, and view the total amount spent.

The project uses CSV files for storing expense data, making it simple and lightweight without requiring a separate database.

## ✨ Features

- ➕ Add new expenses
- 🗂️ Add and delete expense categories
- 🔍 Search expenses by category or description
- 📋 View all expenses
- 🗑️ Delete selected expenses
- 📊 View category-wise expense summary
- 💰 Automatically calculate total expenses
- 📁 Store data using CSV files
- 🖥️ Simple and user-friendly Tkinter interface

## 🛠️ Technologies Used

- Python
- Tkinter
- CSV
- File Handling
